# S5 full-ridge 全局验证预注册方案

## 1. 目标与范围

验证固定 \(p\) full-ridge 的风险、零点导数、最优混合、剂量和汇率结论。实验仍是受控统计模型内的同模型验证，不是非线性、真实视觉或真实机器人外部验证。

主要估计器为标准 full-ridge。主计算使用对标签噪声条件化后的精确设计级风险，高斯 Wishart 样本用 Bartlett 分解生成；另用 `gen_two_domain` 和 `e2_full_ridge` 做独立真实标签/估计器对照。两种证据分别报告。

## 2. 配置

1. `p2_anti_aligned`：非退化零点边界，\(H_{\mathrm{full}}>0\)；
2. `p20_spectral_A`：\(p=20\) 的非退化零点边界；
3. `matched_interior`：matched spectra、内部最优和剂量/汇率；
4. `matched_hits_boundary`：matched-spectrum 剂量触及 \(w=1\)；
5. `flat_boundary`：\(R_0'(0)=0,R_0''(0)>0,R_1'(0)<0\)；
6. `local_global_counterexample`：零点局部有害但全局有益。

主边界样本网格在理论根两侧固定，不根据结果改格子。普通格使用 \(n_r\in\{30,50,70,100,250,450,700,1000,4000\}\) 中与各配置相关的预定点；平坦边界使用 \(10^4,10^5,10^6\)。固定 \(\rho=n_h/n_r\)，不将 \(n_h\) 固定不变。

## 3. 估计量

- 零点设计级条件导数及独立真实估计器配对中心差分；
- 完整 \(R_n(w)\) 网格、最优 \(w_n^*\)、最优收益 \(\mathcal G_n\)；
- 固定 \(w\) 风险与收益，不与全局最优混用；
- matched-spectrum 内点/边界剂量、最优收益修正和汇率极点；
- 平坦边界的 \(n^{-1}\) 权重与 \(n^{-2}\) 收益；
- 局部/全局反例中同时为正的实际零点导数和最优收益。

## 4. 重复、随机流和区间

- 普通格 200 次，主边界格 400 次；bootstrap 1000 次；
- 同一格跨 \(w\) 使用共同设计和共同随机流，真实估计器差分使用同数据同标签配对；
- 两个主边界检验使用 Bonferroni 双侧 97.5% 区间；其他结果为次要或探索性 95% 区间；
- 保存全部重复所需配置和主种子 20261030，追加高重复只用于预注册的噪声诊断，不改主判据。

## 5. 主判据

对每个非退化边界配置：

1. 必须观察到预注册网格内的符号翻转 bracket；
2. 用相邻样本量的线性插值估计根；
3. 计算实测根/理论根及 bootstrap 区间；
4. 只有整个比值区间落在 \([0.8,1.2]\) 内，才记为“边界相容”；
5. 不满足时报告不可分辨或不相容，不能修改网格、删除配置或只引用理论值落在 CI 内。

其他结论不套用 20% 根判据，分别报告预测、实测、区间和失败状态。

## 6. 输出

`M2_实验设计/s5_global/outputs/` 中保存：

- 原始配置、风险和导数 JSON；
- 主边界 bracket、根比值和区间；
- 最优比例、最优收益、剂量和汇率结果；
- 真实 E2 对照；
- 风险/导数/最优收益/剂量图；
- 主张—证据汇总及未通过单元。

任何失败、不可分辨和负面结果均保留。不得用 E1 结果替代 E2 full-ridge，不用 MLP 结果掩盖 full-ridge 失败。
