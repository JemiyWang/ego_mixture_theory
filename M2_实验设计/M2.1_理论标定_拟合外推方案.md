# M2.1 理论标定:拟合-外推方案(batch-1 数据再分析)

> 目的:在不跑任何新训练的前提下,回答"理论 vs 实验的差距(λ* 0.12 vs 0.5)有多少是可标定常数、多少是模型结构缺口",并产出论文候选图(实测点 + 标定理论曲线 + 留出臂外推)。
> 本方案预先注册建模选择与通过判据,防止"调到像为止"。

## 1. 数据与代码基础

| 项 | 路径 | 说明 |
|---|---|---|
| 实验数据 | `l1_pusht/outputs/batch_summary.jsonl` | 19 runs / 4 臂;每 run 20 局闭环 + val_loss |
| 理论参数 | `l1_pusht/outputs/l0_params.json` | p=7;μ=0.05;c_align=−0.508;Δ_φ=18841 |
| 理论求值器 | `l1_pusht/analysis/metrics.py::theory_benefit_curve` | v5 馈通修正逐坐标公式(与论文 overlay 同一段) |
| 样本量 | n_r=80, n_h=100 | 所有 run 一致 |

## 2. 关键建模选择(预先钉死)

1. **拟合主目标 = open-loop val_loss**,不是 coverage。
   理由:理论的风险 R(λ) 是开环预测泛函,val_loss 才是它的合法对应物;coverage 已被 F3 证明会与之发散,若拿 coverage 拟合,会把开闭环缺口揉进自由常数,违背本分析的目的。coverage 只做次要展示并标注 out-of-model。
2. **自由常数:2 个理论 + 2 个链接**。
   - `mu_eff`(有效正则,对数域搜索)——扩散策略无干净对应物,测不准;
   - `delta_scale`(乘在 δ̂ 上的标度)——线性代理 δ̂ 与策略实际感受的失配之间允许一个标度;
   - 链接 `val_loss = A + B·R(λ)`(A、B 仿射,单位换算性质,非理论常数);
   - 其余参数(spectra、beta2、sig_r2/sig_h2)固定为实测值,不调。
3. **标定臂 = naive 50-epoch**(8 个 λ 点,最密、无对齐混入)。
4. **留出臂与旋钮映射**:
   - 150-epoch 臂 → μ 往小动(训练更久 ≈ 有效正则更弱);
   - MMD 0.1 / 1.0 臂 → delta_scale 往小动(对齐压缩有效失配)。

## 3. 协议

1. naive-50 臂 val_loss 上联合最小二乘拟合 (μ, delta_scale);A、B 在每次外层迭代内由线性 lstsq 闭式解出。
2. 冻结 A、B、delta_scale,对 150 臂**仅重拟合 μ**;冻结 A、B、μ,对两条 MMD 臂**仅重拟合 delta_scale**。
3. 记录:各常数取值、各臂 RMSE、序关系是否成立、拟合后理论 λ* 位置。

## 4. 通过判据(预先注册)

- **P-a**(序关系):μ_150 < μ_50;
- **P-b**(单调):delta_scale(mmd0.1)、delta_scale(mmd1.0) ≤ delta_scale(naive);
- **P-c**(形状):留出臂 RMSE ≤ 2 × 标定臂 RMSE。

## 5. 结果解读(预先写明,事后不改)

| 结果 | 结论 |
|---|---|
| 三条全过 | 差距主要是可标定常数;理论具备定量预测力 → 论文加图加段 |
| P-a/P-b 过、P-c 挂 | 常数能吸收方向但形状缺失 → 模型缺结构成分 |
| 全挂 | 结构性差距(模型类/开闭环)→ 支撑 "structural-only" 定位,且指明下一版理论该补什么 |
