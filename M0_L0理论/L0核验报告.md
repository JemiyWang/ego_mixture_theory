## A. §1.4 估计量公式（b(λ) 笔误自查点）——需修正（轻微）

$$(w_r X_r^\top X_r + w_h X_h^\top X_h + \mu I)\,\beta = w_r X_r^\top y_r + w_h X_h^\top y_h,$$
即 $b(\lambda) = w_r X_r^\top y_r + w_h \mathbf{X_h}^\top y_h$。

**文中现状**（第 47 行）：$b(\lambda)$ 的 underbrace 内仍写作 $w_r X_r^\top y_r + w_h \mathbf{X_r}^\top y_h$——**笔误本体还在**，只是紧随其后加了"（第二项应为 $w_h X_h^\top y_h$，笔误自查点，见 §5 核验清单）"的标注。标注所指节号也有误：核验清单在 §7 不在 §5。

**证据**：两个仿真脚本实现的都是正确形式（`l0_monte_carlo.py:59,64`：`bh = Xh.T @ yh; b = wr*br + wh*bh`），故数值结果不受笔误影响。

## B. §2 偏差-方差分解——通过

**独立重推**：记 $A = w_r X_r^\top X_r + w_h X_h^\top X_h + \mu I$（对称）。由 $\mathbb{E}[y_r|X] = X_r\beta^*$、$\mathbb{E}[y_h|X] = X_h(\beta^*+\delta_{\vec{}})$：
$$\mathbb{E}[\hat\beta|X] = A^{-1}\big(w_r X_r^\top X_r\beta^* + w_h X_h^\top X_h(\beta^*+\delta_{\vec{}})\big) = A^{-1}(A-\mu I)\beta^* + w_h A^{-1}X_h^\top X_h\delta_{\vec{}},$$
$$\Rightarrow\ \mathbb{E}[\hat\beta|X]-\beta^* = -\mu A^{-1}\beta^* + w_h A^{-1}X_h^\top X_h\,\delta_{\vec{}}\ \checkmark\ (\text{与文中逐项一致，失配项系数 } w_hA^{-1}X_h^\top X_h\delta_{\vec{}} \text{ 正确})$$
$$\mathrm{Cov}(\hat\beta|X) = A^{-1}\big(w_r^2\sigma_r^2 X_r^\top X_r + w_h^2\sigma_h^2 X_h^\top X_h\big)A^{-1}\ \checkmark\ (A^{-1}\text{ 对称，转置不写自洽})$$
$$\mathcal{R}_T = \mathbb{E}_X\big[\|\mathrm{bias}(X)\|_{\Sigma_r}^2 + \mathrm{tr}(\Sigma_r\mathrm{Cov})\big]\ \checkmark\ (\text{标准全期望分解})$$

## C. §3.1 偏差/方差闭式——通过

**独立重推**：$w_r\mathbb{E}[X_r^\top X_r] = \frac{1-\lambda}{n_r}\cdot n_r I = (1-\lambda)I$；$w_h\mathbb{E}[X_h^\top X_h] = \lambda s^2 I$。代入 $A\approx D I$，$D=(1-\lambda)+\lambda s^2+\mu$：
- 偏差：$\mathrm{bias} \approx (\lambda s^2\delta_{\vec{}} - \mu\beta^*)/D$ ✓；
- $\|\mathrm{bias}\|^2 = \big(\lambda^2 s^4\|\delta\|^2 - 2\lambda s^2\mu\,\delta^\top\beta^* + \mu^2\|\beta^*\|^2\big)/D^2 = \big(\lambda^2 s^4\Delta_\varphi - 2\lambda s^2\mu c + \mu^2 B\big)/D^2$ ✓；
- 方差：$w_r^2\sigma_r^2\,\mathrm{tr}(A^{-1}X_r^\top X_r A^{-1}) \approx \frac{(1-\lambda)^2}{n_r^2}\sigma_r^2\frac{n_r p}{D^2} = \frac{p\sigma_r^2(1-\lambda)^2}{n_r D^2}$；人域项同理得 $p\sigma_h^2\lambda^2 s^2/(n_hD^2)$ ✓。

**数值证据**：用上述公式从零复算两份 JSON 的全部 `R_theory` 曲线，最大偏差 $1.1\times10^{-16}$（v0.2，18 配置 × 8 网格点）与 $2.2\times10^{-16}$（v0.3）——JSON 与 §3.1 公式逐点一致。抽查手算：v0.2 `n_r=50,s²=2,aligned,λ=0.05` 处 $\lambda s^2\delta = 0.05\times2\times0.5\beta^* = \mu\beta^*$，偏差分子 $=0.0025-0.005+0.0025=0$，理论风险 $=200\times(0.9025/50+0.0025\times2/250)/1.21 = 2.98678$，与 JSON `2.9867768595` 一致。

## D. §3.2 R′(0⁺) 求导代数——通过

**独立重推**（商法则）：对 $R = N/D^2$，$R'(0) = \big(N'(0)D(0) - 2N(0)D'(0)\big)/D(0)^3$，$D(0)=1+\mu$，$D'(0)=s^2-1$。
- 偏差分子 $N_b$：$N_b(0)=\mu^2B$，$N_b'(0)=-2s^2\mu c$；
- 方差分子 $N_v$：$N_v(0)=p\sigma_r^2/n_r$，$N_v'(0)=-2p\sigma_r^2/n_r$；
- 合并：$R'(0^+) = \big[{-2s^2\mu c(1+\mu)} - {2\mu^2B(s^2-1)} - \frac{2p\sigma_r^2}{n_r}\big((1+\mu)+(s^2-1)\big)\big]/(1+\mu)^3$，而 $(1+\mu)+(s^2-1) = s^2+\mu$，即文档第三项 $\frac{-2p\sigma_r^2(s^2+\mu)}{n_r(1+\mu)^3}$ ✓。

**sympy 交叉验证**（`.verify_l0/check1_symbolic_and_json.py`）：
```
sympy d/dλ R(0) - 文档公式 化简结果: 0
bias 部分 == 文档 [-2s2·mu·c(1+mu) - 2mu^2 B(s2-1)]/(1+mu)^3 ? True
var  部分 == 文档 [-2 p sr2 (s2+mu)/nr]/(1+mu)^3 ? True
mu→0 极限: -2*p*s2*sr2/nr        （文档称 -2pσ_r²s²/n_r ✓）
```

**三项符号与系数确认**：(i) 交叉项 $-2s^2\mu c(1+\mu)/(1+\mu)^3$——与 $c$ 反号；(ii) 谱宽项 $-2\mu^2B(s^2-1)/(1+\mu)^3$——与 $s^2-1$ 反号；(iii) 方差项 $-2p\sigma_r^2(s^2+\mu)/(n_r(1+\mu)^3)$——恒负。符号条件不等式 $p\sigma_r^2(s^2+\mu)/n_r > -s^2\mu c(1+\mu) - \mu^2B(s^2-1)$ 与 $R'(0^+)<0$ 的移项一致 ✓。

## E. §3.2 文字解读与公式的一致性——通过（附 1 条措辞保留）

4. **"μ→0 时 R′(0⁺)=−2pσ_r²s²/n_r<0 恒成立"** ✓（sympy 验证，见 D）。

## F. §3.3 n_r^crit——需修正（公式/数值对；(·)_− 记号不自洽）

**重推**：$c<0$ 时 $R'(0^+)<0 \iff n_r < p\sigma_r^2(s^2+\mu)/\big({-s^2\mu c(1+\mu) - \mu^2B(s^2-1)}\big)$，不等号方向正确（危害 $H>0$ 时 $n_r < p\sigma_r^2(s^2+\mu)/H$）✓。

**量纲/极限 sanity** ✓：$\mu\to 0 \Rightarrow$ 分母 $\to 0^+$ $\Rightarrow n_r^{crit}\to\infty$（无正则有化时永不弃源，与 §3.2 末条自洽）；$c\to 0^-$ 且 $s^2>1 \Rightarrow$ 分母 $=-\mu^2B(s^2-1)<0$，无有限临界值（恒有益，与 v0.3 orth 两配置理论导数恒负一致）；$n_r^{crit}\propto p$、$\propto\sigma_r^2$、随 $|c|$ 增大而减小，均合理。模型内各量已归一化，分子（$p\sigma_r^2$）与分母（$\mu|c|$、$\mu^2B$）同为风险量纲，可比。

**数值复算** ✓：$p=200,\sigma_r=1,s^2=2,\mu=0.05,c=-2,B=1$：分子 $=200\times2.05=410$；分母 $=0.21-0.0025=0.2075$；$n_r^{crit}=410/0.2075 = 1975.90 \approx 1976$，与文档附录B v0.3 结论 2 一致（注：该算术实际出现在**附录B 的 v0.3 小节**，非附录A）。

**问题——"(·)_− 表示该项为负时才贡献"的写法与自身算术不自洽**：
- 若按标准记法把 $(s^2-1)_-$ 读作**负部函数** $\min(s^2-1,0)$：$s^2=2$ 时 $(1)_-=0$，分母 $=0.21$，$n_r^{crit}=1952.38\ \mathbf{\neq}\ 1976$——与文档自己的计算 $(0.21-0.0025)$ 矛盾；
- 若按慈善读法"整个 $-\mu^2B(s^2-1)$ 项仅当其为负时才计入"：本配置该项 $=-0.0025<0$，计入，得 1976，与算术一致——但此读法在 $s^2<1$ 时会**错误丢弃** $+\mu^2B(1-s^2)$ 这一真实危害项（它使分母更大、临界值更小），公式就错了。
- 实际上分母无需任何截断：$c<0$ 时第一项恒正，第二项符号由 $s^2-1$ 决定，"分母 $>0$ 才有有限临界值"这一条件（文档已有）已足够。

**精确修正文本**（§3.3 公式）：
> $$n_r < n_r^{\mathrm{crit}} := \frac{p\,\sigma_r^2\,(s^2+\mu)}{-s^2\mu c\,(1+\mu) - \mu^2 B (s^2-1)}$$
> （当且仅当分母为正——即净危害 $-s^2\mu c(1+\mu) > \mu^2B(s^2-1)$——时存在有限临界值；若分母 $\le 0$，则 $\mathcal{R}_T'(0^+)<0$ 对所有 $n_r$ 成立，混合恒有益，无临界值。）

（即删去 $(\cdot)_-$ 及其括注，换为上述显式正负条件。）

**另两条轻微 overclaim**：
1. "⟹ $\lambda^*=0$" 是**全局**最优断言；$R'(0^+)>0$ 只给出边际不混。v0.3 `n_r=10000,anti` 的理论与经验 $\lambda^*$ 均为 0（JSON 确认），数值上成立，但一般情形需 $R$ 单峰/单调性，建议标注【待证】或弱化为"边际上不混"。
2. "$n_r^{crit}\propto 1/$失配危害（$\sim A^2$ 的角色）"：本模型分母 $\propto\mu|c|$，对固定方向的失配是**线性**于 $\|\delta\|$；Ben-David 2010 §6 的 $m_T\ge d/A^2$ 对散度参数是**逆二次**。定性类比（危害坐在分母）可接受，"$\sim A^2$ 的角色"建议在脚注中说明指数差异。

## I. §2 结构观察第 1 条的论证严密性——通过（附保留），另发现观察 3 自相矛盾

**观察 1（"μ=0 时失配伤害从二阶进入"）**：论证**精确成立**（不依赖天真确定性等价）：$\mu=0$ 时 $\mathrm{bias}(\lambda) = w_h A(\lambda)^{-1}X_h^\top X_h\,\delta = \lambda\cdot g(\lambda)$，其中 $g$ 在 $\lambda=0$ 附近光滑，**前提**是 $A(0) = X_r^\top X_r/n_r$ 可逆。于是 $\|\mathrm{bias}\|^2 = \lambda^2\,\tilde g(\lambda)$，一阶导数在 0 处为 0 ✓。

**保留（轻微）**：上述可逆性条件（$\mu=0$ 时等价于 $n_r\ge p$，a.s.）文档未写明；其自身 v0.2 的 $\gamma_r=4$（$n_r=50<p=200$）regime 在 $\mu=0$ 下 $A(0)$ 奇异、观察 1 的光滑性论证失效（仿真用 $\mu=0.05$ 故不受影响）。建议补一句"$\mu=0$ 时需 $n_r\ge p$ 保证 $\lambda=0$ 处可逆；$\mu>0$ 时无条件成立"。

**额外发现（本次核验最严重问题）——观察 3 与 §3.3/v0.3 自相矛盾**：观察 3 称"'混合是否有益'的有趣部分**不在 $\lambda\to0$ 的符号（欠参数化时恒正）**"。但：
- §3.3 的 $n_r^{crit}$ 相变**恰恰就是** $\lambda\to0$ 处的符号现象（$R'(0^+)<0 \iff n_r<n_r^{crit}$），且在 $\gamma\to0$ 时精确的 ISO 闭式内发生；
- v0.3 在 $\gamma_r=0.02$（$n_r=10000\gg p=200$，极端"欠参数化"）实测到 $R'(0^+)=+0.313>0$——有害相区出现在欠参数化区域，文档自己的数据直接证伪了该括注；
