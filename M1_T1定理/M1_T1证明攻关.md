## 0. 结构发现（v0.2 修正版）

1. **总体解耦 vs 样本耦合**：M0-COM（对角可交换谱）下，总体协方差对角 ⇒ 估计量的**总体（annealed）行为**逐坐标解耦；但样本 Gram 矩阵 $X_e^\top X_e$ 的非对角元把其他坐标的信号馈入坐标 $j$ 的标签 $T_{ej} = X_{ej}^\top y_e = S_{ejj}\beta_{e,j} + \sum_{k\neq j} S_{ejk}\beta_{e,k} + X_{ej}^\top\varepsilon_e$。馈通项均值为零、方差可解析：
$$\mathrm{Var}\Big(\sum_{k\neq j} S_{ejk}\beta_{e,k}\Big) = n_e\,\lambda^e_j \underbrace{\sum_{k\neq j}\lambda^e_k \beta_{e,k}^2}_{F_{e,j}\ \approx\ F_e\ :=\ \mathbb{E}_{x\sim P_e}\langle\beta_e,x\rangle^2\ \text{（域 }e\text{ 的信号总能量）}}$$
2. **失配障碍的消解（更新 Wu 笔记的判断）**：Wu 笔记指出失配项在 Wu 2026 一般框架中产生四阶预解式夹心泛函、需新 RMT 引理。在我们的对角幂律设定中，失配只进入逐坐标偏置分子（$w_h S_{hj}\delta_j$），馈通与比率涨落都是初等标量随机分析——**v5 数值证据（误差 1–2%）表明对角情形不需要新 RMT 引理**；Wu 管线仍必需的位置：① minimax 最优性声明；② 完整 ridge 估计量（非对角化近似）的 resolvent 修正（v6 检验中）；③ M0-GEN 推广。
3. **证明路线（v0.2）**：逐坐标表示（含馈通）→ 馈通方差的确定性（$\chi^2$ 集中）→ 比率泛函的二阶展开（v4 证据：此项在测试尺度下可忽略，但证明中保留误差项）→ 截断组装 → 相图推论。

## 1. 设定（M0-COM 精确版）

- 坐标 $j = 1, \dots, p$，共享谱基；$\Sigma_r = \mathrm{diag}(\lambda^r_j)$，$\Sigma_h = \mathrm{diag}(\lambda^h_j)$，幂律 $\lambda^e_j \asymp j^{-\alpha_e}$，$\lambda^e_1 = 1$。
- 椭圆约束参数：$\beta^*$ 满足 $\sum_j j^{2s}\beta_j^{*2} \le 1$，边界形态 $\beta_j^{*2} \asymp j^{-(2s+1)}$，$s>0$。
- 标签：$y_r = \langle \beta^*, x_r\rangle + \varepsilon_r$，$\varepsilon_r\sim(0,\sigma_r^2)$；$y_h = \langle \beta_h, x_h\rangle + \varepsilon_h$，$\beta_h = \beta^* + \delta_{\vec{}}$，失配谱分解 $\delta_j$（对角基下的分量）。
- 数据 $n_r, n_h$；混合权重 $\lambda$，每样本权重 $w_r = (1-\lambda)/n_r$、$w_h = \lambda/n_h$；ridge 惩罚 $\mu > 0$。
- 目标：机器人域超额风险 $\mathcal{R}_T(\lambda) = \mathbb{E}\|\hat\beta(\lambda)-\beta^*\|^2_{\Sigma_r}$（**$\Sigma_r$ 加权**；非加权量只作数值对照）。
- **估计量约定（v0.2 新增）**：Level-0 数值与初等理论针对**对角化 ridge 估计量** $\hat\beta_j = (w_r T_{rj} + w_h T_{hj})/(w_r S_{rj} + w_h S_{hj} + \mu)$（即丢弃 $A$ 的非对角元）。完整 ridge 估计量 $A^{-1}b$ 的非对角耦合修正由 Wu 式 resolvent DE 覆盖，v6 数值检验两者差距（预期在谱衰减设定下小）。

## 2. 逐坐标分析（v0.2 修正版）

### 引理 L1（逐坐标表示，对角化估计量）【已证】

对角化估计量逐坐标解耦（平凡）。**但** $T_{ej}$ 含全坐标馈通：
$$T_{ej} = S_{ejj}\,\beta_{e,j} + \underbrace{\sum_{k\neq j} S_{ejk}\,\beta_{e,k}}_{\text{馈通 } U_{ej}} + X_{ej}^\top\varepsilon_e$$
其中 $U_{ej}$ 均值为 0，$\mathrm{Var}(U_{ej}) = n_e \lambda^e_j F_{e,j}$，$F_{e,j} = \sum_{k\neq j} \lambda^e_k \beta_{e,k}^2$（不同 $k$ 交叉项均值零、$S_{ejk}$ 与 $S_{ejj}$ 独立）。$\square$

**评注**：馈通对坐标 $j$ 而言与噪声不可区分——**坐标外信号能量充当额外噪声**。有效噪声
$$\tilde\sigma_{e,j}^2 = \sigma_e^2 + F_{e,j} \;\approx\; \sigma_e^2 + F_e,\qquad F_e = \textstyle\sum_k \lambda^e_k \beta_{e,k}^2$$
$F_e$ 是域 $e$ 信号在其自身几何下的总能量（不依赖 $j$ 到领头阶）。**含义**：人域谱越重尾（$\alpha_h$ 小），$F_h$ 越大，人域数据的逐坐标有效信噪比越低——这是"宽覆盖"的隐性代价项，与收益项（谱宽）对冲，是相图结构的微观来源之一。

### 引理 L2（条件 MSE 的精确形式，含馈通）【已证】

记 $\hat D_j = w_r S_{rjj} + w_h S_{hjj} + \mu$。条件于设计矩阵：
$$\mathbb{E}\big[(\hat\beta_j-\beta^*_j)^2 \,\big|\, X\big] = \frac{\big(w_h S_{hjj}\delta_j - \mu\beta^*_j + w_r U_{rj} + w_h U_{hj}\big)^2}{\hat D_j^2} + \frac{w_r^2\sigma_r^2 S_{rjj} + w_h^2\sigma_h^2 S_{hjj}}{\hat D_j^2}$$
（馈通进入偏差分子的随机部分；其条件均值非零但跨设计均值为零。）$\square$

### 引理 L3（逐坐标确定性等价，含馈通）【数值确认，严格误差界草稿】

取二阶 delta-method 展开（$S_{ejj}\sim\lambda^e_j\chi^2_{n_e}$，馈通按引理 L1 方差处理，馈通与 $\hat D_j$ 独立 $\Rightarrow$ 无协方差项）：

$$\mathbb{E}\,\mathrm{MSE}_j \;\approx\; \frac{N_{0j}^2}{D_j^2} + \frac{\mathrm{Var}(\hat N_j)}{D_j^2} - \frac{4 N_{0j}\,\mathrm{Cov}(\hat N_j,\hat D_j)}{D_j^3} + \frac{3N_{0j}^2\,\mathrm{Var}(\hat D_j)}{D_j^4}$$

其中 $D_j = (1-\lambda)\lambda^r_j + \lambda\lambda^h_j + \mu$，$N_{0j} = \lambda\lambda^h_j\delta_j - \mu\beta^*_j$，及闭式
$$\mathrm{Var}(\hat N_j) = 2\lambda^2(\lambda^h_j\delta_j)^2/n_h \;+\; \frac{(1-\lambda)^2(\sigma_r^2+F_r)\lambda^r_j}{n_r} + \frac{\lambda^2(\sigma_h^2+F_h)\lambda^h_j}{n_h}$$
$$\mathrm{Cov}(\hat N_j, \hat D_j) = 2\lambda^2\delta_j(\lambda^h_j)^2/n_h, \qquad \mathrm{Var}(\hat D_j) = 2\Big[\frac{(1-\lambda)^2(\lambda^r_j)^2}{n_r} + \frac{\lambda^2(\lambda^h_j)^2}{n_h}\Big]$$

**数值验证结论（v3→v4→v5，`l1_com_v*.py`）**：
- 零阶（总体代入）公式系统低估 30–90%（v3）；
- 仅加比率涨落修正几乎不闭合差距（v4）——证明主误差源是馈通；
- **加馈通修正后（v5）：分箱中位相对误差 0.6–1.6%，总量与 $\Sigma_r$ 加权总量误差 ≤2%**（3 配置 × 2 λ，REPS=200，200k 坐标-重复量级）——L3 的公式形式数值确认；
- 遗留：涨落项（后两项）在测试尺度下贡献 <1%，证明中作为误差项保留即可。

### 引理 L4（截断组装）【草稿】

信息贫乏坐标（$D_j \lesssim$ 涨落尺度）上估计收缩至 ≈0，风险贡献 ≈ $\lambda^r_j\beta_j^{*2}$。自洽截断 $m(\lambda,\mu) = \max\{j : D_j \ge \kappa\,\eta_j\}$，$\eta_j$ 为 $\hat D_j$ 涨落尺度：
$$\mathcal{R}_T(\lambda) = \underbrace{\sum_{j>m}\lambda^r_j\beta_j^{*2}}_{\asymp\, m^{-(\alpha_r+2s)}} + \sum_{j\le m}\lambda^r_j\,\mathbb{E}\,\mathrm{MSE}_j + \text{(误差)}$$
（$\Sigma_r$ 加权使截断尾为 $m^{-(\alpha_r+2s)}$，与 Wu 的非加权 $m^{-2s}$ 不同——对接见 Q1。）

## 3. 定理 T1 的精确陈述（草案 v0.2）【数值确认形式，严格化进行中】

**设定**：§1 的 M0-COM；$p, n_r, n_h \to \infty$，$p/n_r \to \gamma_r$，$p/n_h \to \gamma_h$；$\mu>0$ 固定或适当标度。

**陈述分两层**（v6 数值证据驱动）：

- **T1-a（对角化 ridge，初等完整理论）**：对角化估计量的目标域超额风险满足（几乎必然，误差率由 L3 给出）
$$\bar{\mathcal{R}}_T^{\mathrm{diag}}(\lambda) \;\asymp\; \inf_{m}\Big\{ m^{-(\alpha_r+2s)} + \sum_{j\le m} \lambda^r_j\Big[ \frac{(1-\lambda)^2\tilde\sigma_r^2\,\lambda^r_j/n_r + \lambda^2\tilde\sigma_h^2\,\lambda^h_j/n_h}{D_j^2} + \Big(\frac{\lambda\lambda^h_j\delta_j}{D_j}\Big)^2 + \Big(\frac{\mu\beta^*_j}{D_j}\Big)^2 \Big] \Big\}$$
其中 $\tilde\sigma_e^2 = \sigma_e^2 + F_e$（馈通修正有效噪声），$D_j = (1-\lambda)\lambda^r_j + \lambda\lambda^h_j + \mu$。**数值精度 1–2%（v5）**。
- **T1-b（完整 ridge，主定理）**：$\bar{\mathcal{R}}_T^{\mathrm{full}}(\lambda)$ 由 Wu 式 resolvent DE 给出方差部分 + 失配偏置扩展（四阶泛函 $\mathrm{Tr}(C_r G S_h \delta\delta^\top S_h G)$ 的 DE——WP1 的真正技术核心；对角极限须回收 T1-a，v6 提供数值锚点与差距量级）。

与猜想 P0.2（L0 文档附录 B）的关系：**P0.2 的形式成立，但需两处修正**——① 方差单价中的 $\sigma_e^2$ 必须替换为 $\tilde\sigma_e^2 = \sigma_e^2 + F_e$（馈通自能量，v5 的定量证据）；② 逐坐标失配单价 $(w_j^{(h)}\delta_j)^2$ 形式确认（$w_j^{(h)} = \lambda\lambda^h_j/D_j$）。对完整 ridge，馈通项是方差的**上界**（v6）。

**推论 C1（边际收益符号条件，P0.1-COM）【草稿】**：对 $\lambda$ 逐项求导组装 $\bar{\mathcal{R}}_T'(0^+)$ 的显式不等式；ISO 极限（$\alpha_e \to$ 常数谱、$c$ 投影）须回收 L0 §3.2 的已核验公式。

**推论 C2（相图与两个相变）【草稿】**：$(n_h/n_r, \Delta_\varphi, \alpha_r-\alpha_h)$ 空间的 $\lambda^*>0$ 区域边界；Ben-David 两相变的 COM 恢复（$n_r$ 阈值经 C1；$n_h$ 阈值经 $\gamma_h$ 进入方差项——v2 数值中 $\lambda^*$ 对谱系的依赖（A 系 0.10 vs B 系 0.30–0.50）是待解释的定性锚点）。

**推论 C3（汇率定理 T2 雏形）**：$n_{\mathrm{eff}} = n_r + \kappa_{\mathrm{ex}} n_h$，$\kappa_{\mathrm{ex}}$ 由失配谱与 $\tilde\sigma$ 比决定。

## 附录：推论 C1 逐坐标推导与 v7 理论相图（2026-10-23）

### C1 推导（边际收益符号条件，对角化估计量）【数值确认：解析导数 vs 差分误差 <1%】

对 v5 公式逐坐标求导（$a_j = \lambda^r_j$，$b_j = \lambda^h_j$，$D_0 = a_j+\mu$，$V_{r,j} = \tilde\sigma_r^2 a_j/n_r$）：

$$\mathrm{MSE}_j'(0) = \frac{-2\mu\beta^*_j b_j \delta_j - 2V_{r,j}}{D_0^2} \;-\; \frac{2\big(V_{r,j} + \mu^2\beta_j^{*2}\big)(b_j - a_j)}{D_0^3}$$

整理为**逐坐标边际收益**（符号翻转后，>0 表示坐标 $j$ 受益于边际混合）：

$$\mathrm{benefit}_j \;\propto\; \underbrace{\mu\beta^*_j b_j \delta_j}_{\text{A：失配对齐项（坐标级 }c_j\text{）}} \;+\; \underbrace{V_{r,j}\,D_0}_{\text{B：方差收益（恒正）}} \;+\; \underbrace{\big(V_{r,j} + \mu^2\beta_j^{*2}\big)\,(b_j - a_j)}_{\text{C：谱宽项（}b_j>a_j\text{ 即人域谱在该坐标更重时为正）}}$$

**这是 ISO 三项结构（L0 §3.2）的坐标级分解**：A 项只经 $\mu$ 存在（正则化承载对齐效应）；B 项随 $n_r$ 消失（diminishing returns）；C 项逐坐标依赖谱差 $b_j/a_j = j^{\alpha_r-\alpha_h}$——谱差大时 C 在低频为负、高频为正，与 v2 观察到的"失配谱效应随谱差翻转"同源。$\bar{\mathcal{R}}_T'(0^+) = \sum_j a_j\,\mathrm{MSE}_j'(0)$，幂律下和式可由积分估计——相变条件即其符号翻转。

## §7 证明草稿：L3（逐坐标确定性等价）完整版 + L4（截断组装）【草稿 v0.1，2026-10-23】

本节给出 T1-a（对角化估计量）的完整证明骨架。所有分析步骤为初等标量随机分析；标注【机械】= 纯簿记（矩计算/常数收集），【待严格化】= 需补完整的技术引理表述。

### 7.1 记号（单坐标，省略下标 j）

- $U_r \sim \chi^2_{n_r}$，$U_h \sim \chi^2_{n_h}$ 独立；$S_e = \lambda^e U_e$（$\mathbb{E} S_e = n_e\lambda^e$，$\mathrm{Var}(S_e) = 2n_e(\lambda^e)^2$，三阶中心矩 $8n_e(\lambda^e)^3$）。
- $\hat D = w_r S_r + w_h S_h + \mu$，$D = \mathbb{E}\hat D$；涨落尺度 $\eta := \sqrt{8\log(4p/\delta)}\,\big(\frac{(1-\lambda)\lambda^r}{\sqrt{n_r}} + \frac{\lambda\lambda^h}{\sqrt{n_h}}\big)$（$p$ 为坐标数，供后续 union bound）。
- 分子 $\hat N = N_0 + \tilde n$，$N_0 = \lambda\lambda^h\delta - \mu\beta^*$（系统部分期望），$\tilde n$ 零均值且
$$\mathrm{Var}(\tilde n) = \underbrace{\tfrac{2\lambda^2(\lambda^h\delta)^2}{n_h}}_{\text{失配涨落}} + \underbrace{\tfrac{(1-\lambda)^2\tilde\sigma_r^2\lambda^r}{n_r} + \tfrac{\lambda^2\tilde\sigma_h^2\lambda^h}{n_h}}_{\text{噪声+馈通（}\tilde\sigma_e^2 = \sigma_e^2 + F_e\text{）}}$$
（馈通项 $\mathrm{Var}(w_e U_{ej}) = w_e^2 n_e\lambda^e F_e$ 化入 $\tilde\sigma^2$ 后按权重化简；$F_e$ 的自身集中由 $\beta^*$ 椭圆约束下 $\sum_k \lambda^e_k\beta_{e,k}^2$ 的确定性给出【机械】。）

### 7.2 引理 L3（正式陈述）

**条件**：$D \ge 2\eta$（坐标信息充裕；union bound 后对 $j \le m$ 一致成立，概率 $\ge 1-\delta$）。

**结论**：
$$\Big|\ \mathbb{E}\big[(\hat\beta-\beta^*)^2\big] - \mathrm{MSE}^{\mathrm{v5}}\ \Big| \;\le\; C\Big(\frac{\eta}{D}\Big)^3 \cdot \frac{\overline{N}^2}{D^2} + O\big(\delta\, \mu^{-2}\, \overline{N}^2\big)$$
其中 $\overline{N}^2 := N_0^2 + \mathrm{Var}(\tilde n)$，$C$ 为绝对常数，$\mathrm{MSE}^{\mathrm{v5}}$ 为含馈通与二阶涨落修正的公式（§2 引理 L3）：
$$\mathrm{MSE}^{\mathrm{v5}} = \frac{N_0^2}{D^2} + \frac{\mathrm{Var}(\tilde n)}{D^2} - \frac{4N_0\,\mathrm{Cov}(\tilde n, \hat D)}{D^3} + \frac{3N_0^2\,\mathrm{Var}(\hat D)}{D^4}$$
（$\mathrm{Cov}(\tilde n,\hat D) = \frac{2\lambda^2\delta(\lambda^h)^2}{n_h}$——只有失配的系统部分与 $\hat D$ 相关；噪声与馈通同 $S_{ejj}$ 独立【机械：独立性核查】。）

### 7.3 证明

**步骤 1（$\hat D$ 集中，【标准】）**：Laurent–Massart 的 χ² 尾界：$\Pr(|U_e - n_e| \ge 2\sqrt{n_e x}) \le 2e^{-x}$（$x$ 适当范围）。故以概率 $\ge 1-\delta$：对所有坐标一致地 $|\hat D - D| \le \eta$（$\eta$ 定义中已含 $\log p$）。在坏事件上用 $|\hat N^2/\hat D^2| \le \hat N^2\mu^{-2}$ 与 $\hat N$ 的次高斯/多项式矩控制，贡献 $O(\delta\cdot \mu^{-2}\overline{N}^2)$ 阶【机械：四阶矩存在性由 χ² 与（条件）高斯的矩界给出】。

**步骤 2（好事件上的 Taylor 展开，【标准】）**：$f(x) = x^{-2}$，$|Δ| \le \eta \le D/2$ 时
$$f(D+Δ) = D^{-2} - 2Δ D^{-3} + R,\qquad |R| \le \tfrac12 \max_{\xi\in[D-\eta,D+\eta]} 6\xi^{-4}\,Δ^2 \le 48\,\eta^2/D^4$$

**步骤 3（矩展开，【机械】）**：
$$\mathbb{E}[\hat N^2 f(\hat D)] = \frac{\mathbb{E}\hat N^2}{D^2} - \frac{2\,\mathbb{E}[\hat N^2 Δ]}{D^3} + \mathbb{E}[\hat N^2 R]$$
其中 $\mathbb{E}\hat N^2 = N_0^2 + \mathrm{Var}(\tilde n)$；
$$\mathbb{E}[\hat N^2 Δ] = \underbrace{N_0^2\,\mathbb{E}Δ}_{=0} + 2N_0\,\mathrm{Cov}(\tilde n, \hat D) + \mathbb{E}[\tilde n^2 Δ]$$
第三项 $\mathbb{E}[\tilde n^2 \Delta]$ 含 χ² 三阶中心矩与噪声-馈通的混合矩：**实际为精确闭式而非余项**——把 $\tilde n = a_1 v_h + \zeta$（$a_1 = \frac{\lambda}{n_h}\lambda^h\delta$ 为失配涨落系数，$v_h = U_h - n_h$，$\zeta$ = 噪声+馈通+机器人侧各项，与 $(v_r, v_h)$ 独立）代入展开，交叉项全部由独立性/零均值消失，唯一存活项为
$$\mathbb{E}[\tilde n^2 \Delta] = a_1^2\, w_h \lambda^h\, \mathbb{E}[v_h^3] = a_1^2\, w_h \lambda^h \cdot 8n_h = \frac{8\lambda^3 (\lambda^h)^3 \delta^2}{n_h^2}$$
（对风险贡献 $-2\mathbb{E}[\tilde n^2\Delta]/D^3 < 0$，量级 $O(\lambda^3\delta^2/(n_h^2 D^3))$，相对主项可忽略但解析精确）。**原"唯一实质簿记"项就此闭合。**
余项：$|\mathbb{E}[\hat N^2 R]| \le 48\eta^2 D^{-4}\,\mathbb{E}\hat N^2 = O((\eta/D)^2\cdot \overline N^2/D^2)$。

**步骤 4（收集）**：合并即得 L3 结论，主误差 $(\eta/D)^3 \overline N^2/D^2$。**量级核查**：$\eta/D \sim n_{\min}^{-1/2}\cdot$（谱加权因子），故相对误差 $O(n_{\min}^{-3/2})$——在 $\gamma$ 固定（$p\propto n$）时随维数消失，与 v5 数值（1–2%）量级一致 ✓。

### 7.4 引理 L4（截断组装）【草稿】

- **截断坐标**（$j > m$，$D_j < 2\eta_j$）【已闭合】：此簇坐标 $D_j < 2\mu$（因 $\eta_j$ 在截断边界处 $< D_j/2$ 而信息项更小），故分母由 $\mu$ 主导，$\mathbb{E}\hat\beta_j = \beta^*_j(1 - \mu/D_j) + O(\eta_j/D_j)$ 且 $\mu/D_j > 1/2$——收缩率有界：$\mathbb{E}(\hat\beta_j - \beta^*_j)^2 = \Theta(\beta_j^{*2})$（下界由 $\mu/D_j > 1/2$ 给出，上界由 $|\hat\beta_j| \le |\hat N_j|/\mu$ 与 $N_0 = -\mu\beta^*_j$ 的相消给出；常数因子精度对 $\asymp$ 阶足够，$1+o(1)$ 精度需完整 DE——标注为 T1-b 范畴）。总贡献 $\asymp \sum_{j>m}\lambda^r_j\beta_j^{*2} \asymp m^{-(\alpha_r+2s)}$（幂律尾部积分）。
- **保留坐标**（$j \le m$）【已闭合】：union bound + L3 逐坐标应用。逐坐标相对误差 $(\eta_j/D_j)^3$ 在 $j \le m$ 上**不一致小**（近截断边界 $\eta_j/D_j \to 1/2$）——处理：把保留簇细分为"良条件核心"（$D_j \ge \kappa\eta_j$，$\kappa$ 大，相对误差 $O(\kappa^{-3})$ 一致成立）与"边界带"（$2\eta_j \le D_j < \kappa\eta_j$）。边界带宽度在幂律谱下为 $o(m)$，其坐标的风险介于主项与截断值之间，贡献被截断项常数吸收【机械：带宽估计 = 解 $D_j = \kappa\eta_j$ 的幂律方程】。故总和的相对误差 = $O(\kappa^{-3}) + o(1)$（带贡献），主项阶不被误差和超过。
- **组装**：
$$\mathcal{R}_T(\lambda) = \underbrace{\sum_{j>m}\lambda^r_j\beta_j^{*2}}_{m^{-(\alpha_r+2s)}} + \sum_{j\le m}\lambda^r_j\,\mathrm{MSE}^{\mathrm{v5}}_j \;\cdot\; \big(1 + O(n_{\min}^{-3/2})\big)$$
对 $m$ 取 inf 得 T1-a 的陈述（§3）。

## 附录 3：推论 T2（汇率定理）定理化文本（2026-10-23，M2 任务 T2.3）

### T2 的精确陈述【草稿+数值支持】

**定义（汇率）**：在 §1 的 M0-COM 设定下，定义 ego-遥操作汇率 $\kappa_{\mathrm{ex}}$ 为方程
$$\bar{\mathcal{R}}_T\big(\lambda^*;\, n_r, n_h\big) = \bar{\mathcal{R}}_T\big(0;\, n_r + \kappa_{\mathrm{ex}}\, n_h\big)$$
的解（右侧为纯机器人域、样本量放大后的风险）。$\kappa_{\mathrm{ex}} \in [0, \infty)$：$\kappa_{\mathrm{ex}} = 0.2$ 即"5 小时 ego ≈ 1 小时遥操作"；$\kappa_{\mathrm{ex}} > 1$ 表示 ego 数据**小时比小时**比遥操作更值钱。

**推论 T2（汇率的单调结构）**：在 C1 的显式不等式与 v5 风险公式下，$\kappa_{\mathrm{ex}}$ 满足：

1. **对谱差单调增**：$\partial \kappa_{\mathrm{ex}} / \partial(\alpha_r - \alpha_h) > 0$——人域谱相对更重（覆盖更多机器人数据难以触及的方向），汇率越高；极限情形（$\alpha_r - \alpha_h$ 大、人域独占覆盖高频方向簇）时 $\kappa_{\mathrm{ex}} \ge 1$，纯机器人加样**按任何比例**都无法复现混合收益（v7 数值中 A 系撞上限 1.0 即此相区）；
2. **对失配单调减**：$\kappa_{\mathrm{ex}}$ 随 $\|\delta\|_{\text{eff}}$（经 $w_j^{(h)}$ 加权的失配能量）单调下降；反对齐（$c<0$）时存在阈值 $\Delta_c(n_r, \mu)$ 使 $\kappa_{\mathrm{ex}} = 0$（有害相区边界，见 v8）；
3. **对 $n_r$ 单调减**：$\partial \kappa_{\mathrm{ex}}/\partial n_r < 0$（diminishing returns 的汇率表述；R6 的定量对应）。

**证明路线**：由 T1-a 的逐坐标风险公式，$\bar{\mathcal{R}}_T(0; n_r')$ 对 $n_r'$ 的依赖只经 $V_{r,j} = \tilde\sigma_r^2 a_j/n_r'$ 进入（方差单价线性反比样本量）；比较混合最优风险与纯机器人风险的逐坐标差，汇率方程化为
$$\sum_j a_j\Big[\mathrm{MSE}_j^{\mathrm{det}}(\lambda^*) - \mathrm{MSE}_j^{\mathrm{det}}\big(0; n_r + \kappa n_h\big)\Big] = 0$$
各项单调性由 C1 的三分解（A/B/C 项对 $(\alpha_r-\alpha_h)$、$\delta$、$n_r$ 的符号）逐项读出【草稿：单调性的严格化需要逐项符号分析，预期无概念困难】。

### 与经典理论的锚定（写作时引用）

- **Ben-David–Shalev-Shwartz–Urner 2014**：数量补偿质量的放大因子 $C^{-(d+1)}$——κ_ex 是其"混合 ridge + 幂律谱"实例化，把密度比 $C$ 换成可测的谱/失配量；

## §8 T1-b 对接草案：完整 ridge 的失配偏置确定性等价（2026-10-23）【猜想级】

### 8.1 待计算的精确对象

完整 ridge $\hat\beta = A^{-1}b$，$A = w_r S_r + w_h S_h + \mu I$（$S_e = X_e^\top X_e$，**含非对角元**）。失配经标签进入 $b$：$b = w_r X_r^\top y_r + w_h X_h^\top y_h$，$\mathbb{E} b = w_r S_r \beta^* + w_h S_h(\beta^* + \delta_{\vec{}})$，故
$$\mathbb{E}\hat\beta - \beta^* = -A^{-1}\mu\beta^* + A^{-1} w_h S_h \,\delta_{\vec{}}$$
失配偏置对 $\Sigma_r$ 加权风险的贡献为
$$\mathcal{B}_{\mathrm{mis}} = \delta_{\vec{}}^\top \,\underbrace{w_h^2\, S_h A^{-1} \Sigma_r A^{-1} S_h}_{\text{四阶夹心（}G = A^{-1}\text{ 为 resolvent）}}\, \delta_{\vec{}}$$
——即 Wu 笔记指出的 $\mathrm{Tr}$ 型四阶泛函（对角设定下 $S_h$ 与 $A^{-1}$ 不对易时非平凡）。

### 8.2 猜想的形式（锚定对角极限）

**猜想 T1-b-bias**：可交换幂律谱下，
$$\mathcal{B}_{\mathrm{mis}} \;\to\; \sum_j \lambda^r_j \Big(\frac{\lambda\lambda^h_j}{D^{\mathrm{full}}_j}\,\delta_j\Big)^2 \cdot \big(1 + o(1)\big)$$
其中 $D^{\mathrm{full}}_j$ 为完整 ridge 的确定性等价分母（含 resolvent 的自洽修正，区别于对角化的 $D_j$）——**与 T1-a 的失配单价 $(w_j^{(h)}\delta_j)^2$ 同构，只是 $w_j^{(h)}$ 由完整 DE 的权重给出**。

支持证据：① 对角极限回收 T1-a（v5 精度 1–2%）；② v6 实测：完整 ridge 的 Σ_r 加权风险与 T1-a 预测在 A 系差 8%、B 系差 28%——差距全部来自方差侧（馈通高估），**偏置侧无独立证据表明形式改变**；③ 机制上失配是确定性的均值偏移，resolvent 对它的加权与对信号能量的加权同源。

### 8.3 证明策略（若在 M2 后启动）

1. Wu Theorem 6 管线给出 $G$ 的 DE（方差部分现成）；
2. 新增引理：$\delta_{\vec{}}^\top S_h G \Sigma_r G S_h \delta_{\vec{}}$ 的 leave-one-out 分解——$\delta_{\vec{}}$ 固定 ⟹ 只对 $S_h$ 的行做 LOO，结构比全随机二次型简单；预期经其附录的 resolvent 恒等式链闭合；
3. 退路（已在 §7.5 备案）：低秩失配（$r$ 个方向）时夹心退化为 $r$ 个标量 DE 的组合。

### 8.4 T1-b 的数值验证预案

v6 的骨架已具备：同一批数据上对照 {完整 ridge 经验值, T1-a 预测, T1-b 猜想预测（$D^{full}_j$ 用 Wu DE 的数值解代入）}；判定标准：T1-b 预测把 v6 的 8–28% 差距压到 ≤5% 且 λ\* 预测改进。

### 8.5 状态

【猜想级】——本轮仅完成形式化与证据锚定；证明与数值验证留给 M2 之后的理论回合（不阻塞 M2 实验线）。

## 附录 4：C1 组装的证伪与修正迭代（v9，2026-10-23）【重要的负面结果】

**检验对象**：附录 2 的 C1 领头阶组装预测 $n_r^{crit} \propto \tilde\sigma_r^2/(\mu^{2.05}\cdot|\delta|_{eff})$（谱系 A：$1+(\alpha_r-\alpha_h+1)/\alpha_r = 2.05$）。

**诊断（失败原因已定位）**：

1. 组装只保留了 $j \le j_\mu$ 区间的失配危害，**漏掉了 $j > j_\mu$ 区间的危害通道**：那里 $D_0 \approx \mu$，交叉项 $a_j\beta^*_j b_j\delta_j/\mu^2$ 被 $\mu^{-2}$ 放大，其贡献 $\asymp |\delta|\mu^{-1}j_\mu^{-(\alpha_r+\alpha_h+s-1/2)}$ 与 $j\le j_\mu$ 部分同阶（不可丢弃）。计入后修正预测指数 $\approx -1.25$（vs 实测 −1.08，仍有差距——$j_\mu$ 软截断（$D_0 = a_j + \mu$ 光滑过渡）与常数因子所致）；
2. δ-阈值行为的来源：失配同时进入 $F_h$（馈通能量 $\sum \lambda^h_k(\beta^*_k+\delta_k)^2$ 随 $\|\delta\|$ 二次增长），失配不只是危害项还抬升人域有效噪声——小失配时收益/危害平衡中收益通道（经 $\tilde\sigma_h^2$ 下压人域权重）部分抵消危害，产生阈值。

**未受影响的结果**：v7/v8 相图与 κ_ex 数值全部由完整 v5 公式直接计算（不经组装近似），继续有效；被证伪的只是附录 2 的闭式标度形式。

**状态修正**：C1 显式不等式回到【草稿】；下一步（理论回合）：含双区间危害通道的完整组装 + 与 v9 数值的逐项对账。这是 Hessian 范式的正常工作流——廉价证伪发现了组装的失效位置。

### 研究方法论注记

本次失败的价值：它表明**相变边界对 $\mu$ 的标度是一个敏感的可区分量**（指数 −2.05 vs −1.25 vs −1.076 差异大），适合作为论文中"理论-仿真同图"的定量检验目标（比 λ* 位置更敏感）。v9 的检验管线（纯公式二分扫描 + 幂律拟合）可原样复用于后续任何候选组装。

## 附录 5：修正后的相变判据——H 泛函（v11 数值精确确认，2026-10-23）

**这是 v9 证伪事件的最终理论形态，取代附录 2 的（失败的）幂律标度组装。**

### 判据（C2 的修正形式）【数值确认：精确】

定义渐近边际危害泛函（$n_r \to \infty$、$n_h/n_r$ 固定、$B$ 项消失后的 $\bar{\mathcal{R}}_T'(0^+)$）：
$$H(\mu, \delta_{\vec{}}, \text{谱}) \;:=\; \underbrace{2\mu \sum_j \frac{a_j \beta^*_j b_j |\delta_j|}{D_{0,j}^2}}_{A_\infty\text{：失配危害（反对齐时）}} \;-\; \underbrace{2\mu^2 \sum_j \frac{a_j \beta_j^{*2} (b_j - a_j)}{D_{0,j}^3}}_{C_\infty\text{：更宽人域谱的收缩减免收益}}$$

**定理形式（草稿）**：
1. $H \le 0$ ⟹ 混合在边际上对所有 $n_r$ 有益（无有害相区）；
2. $H > 0$ ⟹ 存在有限 $n_r^{\mathrm{crit}} = K/H$，$K = 2\tilde\sigma_r^2\,(S_1+S_2)$（$S_1 = \sum_j a_j^2/D_0^2$，$S_2 = \sum_j a_j^2(b_j-a_j)/D_0^3$ 的方差侧系数和）——**$n_r^{\mathrm{crit}}$ 与 $H$ 严格反比**。

### 数值确认（v11，`l1_c1_H_criterion.py`，p=1000, μ=0.05, 谱系 A）

1. **阈值预言精确**：$A_\infty \propto \|\delta\|$（6.975e-3/单位），$C_\infty$ 与 δ 无关（4.700e-3）→ 预言阈值 $\|\delta\|^* = 0.674$；与 v9 观测（0.5 无临界、1.0 有）一致，且 $H(0.674) = +1.2\times10^{-6} \approx 0$ 处精确穿越；
2. **$n_r^{\mathrm{crit}} \cdot H = 25.866$ 在三个失配量级（0.75/1.0/2.0）上恒为常数**（显示精度内）——反比关系精确；
3. 回溯 ISO：L0 §3.3 的 $n_r^{crit} = p\tilde\sigma^2(s^2+\mu)/[-s^2\mu c(1+\mu) - \mu^2 B(s^2-1)]$ 正是 H-形式（分母 = ISO 版 H）——**ISO 与 COM 两级理论在 H-判据下统一** ✓。

### 对既有文档的修订

- 附录 2 的 $n_r^{crit} \propto \mu^{-2.05}$ 幂律组装**作废**（v9 证伪）；正确形式是 $n_r^{crit} = K/H(\mu)$，$\mu$ 依赖经 $A_\infty$（∝μ·谱和）与 $C_\infty$（∝μ²·谱和）进入，非纯幂律；
- v9 的"μ 指数 −1.076"实测值是 $H(\mu)$ 在非渐近 μ 区间的有效对数斜率，不再是检验目标；**新的敏感检验量 = H 判据 + $n_r^{crit}\cdot H$ 常数性**（v11 管线可复用）；
- 物理图景修正：$n_r \to \infty$ 时混合收益**不消失而是趋于 $-C_\infty$**（μ>0 时）——更宽人域谱分担收缩偏差的通道在大数据端仍活跃；Ben-David 式"弃源相变"只在失配危害超过该通道时存在。这与经典直觉（无限目标数据→弃源）的关系：**μ→0 时 $C_\infty$ 消失，$H = A_\infty > 0$ 恒成立（$c<0$ 时），经典相变恢复**——$\mu$（正则化/早停）是本模型中"混合在大数据端仍有益"现象的全部载体。

## §9 T1-a 定理文本（近论文形式草案，2026-10-23）

> 用途：M1 出口门"定理定稿"的底稿；写作时再转为英文并补常数。所有证明引用 §7（L1–L4）。

**设定（Assumptions）**

- **A1（双域数据模型）**：坐标 $j=1,\dots,p$；观测 $x_e = \Sigma_e^{1/2} u_e$，$u_e$ 标准高斯，$\Sigma_e = \mathrm{diag}(\lambda^e_j)$ 对角，幂律 $\lambda^e_j \asymp j^{-\alpha_e}$，$\lambda^e_1=1$；
- **A2（标签）**：$y_r = \langle\beta^*, x_r\rangle + \varepsilon_r$；$y_h = \langle\beta^*+\delta_{\vec{}}, x_h\rangle + \varepsilon_h$；噪声方差 $\sigma_e^2$；$\beta^*$ 满足椭圆约束 $\sum_j j^{2s}\beta_j^{*2}\le 1$；
- **A3（混合估计量）**：对角化 ridge，$\hat\beta_j = (w_rT_{rj}+w_hT_{hj})/(w_rS_{rj}+w_hS_{hj}+\mu)$，$w_r=(1-\lambda)/n_r$，$w_h=\lambda/n_h$，$\mu>0$；
- **A4（渐近）**：$n_r, n_h \to \infty$，比率 $\rho = n_h/n_r$ 固定；$p$ 固定或多项式增长（$\log p$ 进入集中界）。

**定理 T1-a（混合对角化 ridge 的风险刻画）**：在 A1–A4 下，以概率 $\ge 1-\delta$，
$$\Big|\ \mathcal{R}_T(\lambda) - \bar{\mathcal{R}}_T(\lambda)\ \Big| \le C\big(\kappa^{-3} + n_r^{-3/2}\big)\cdot \bar{\mathcal{R}}_T(\lambda) + \varepsilon_\delta$$
其中 $\bar{\mathcal{R}}_T(\lambda) = \sum_{j>m}\lambda^r_j\beta_j^{*2} + \sum_{j\le m}\lambda^r_j\,\mathrm{MSE}^{\mathrm{v5}}_j(\lambda)$，$m$ 为自洽截断（§7.4），$\mathrm{MSE}^{\mathrm{v5}}_j$ 为逐坐标闭式（引理 L3，含馈通修正有效噪声 $\tilde\sigma_e^2 = \sigma_e^2 + F_e$，$F_e$ 为域信号能量），$\varepsilon_\delta$ 为集中例外项。
**证明**：引理 L1（逐坐标表示，§2）→ L2（条件 MSE，§2）→ L3（逐坐标确定性等价，§7.2–7.3，χ² 集中 + 二阶展开 + 三阶项闭式 $8\lambda^3(\lambda^h_j)^3\delta_j^2/n_h^2$）→ L4（截断组装，§7.4：截断坐标 $\Theta(\beta_j^{*2})$ 收缩 + 边界带吸收）。∎

**推论 C1（边际收益符号）**：$\bar{\mathcal{R}}_T'(0^+) = \sum_j a_j\big[A_j + B_j + C_j\big]$（附录 2 三项分解）；$\mu=0$ 时 $= -(2\tilde\sigma_r^2/n_r)\sum_j j^{\alpha_r-\alpha_h} < 0$ 恒成立。

**推论 C2（相变判据，H 泛函）**：定义 $H = A_\infty - C_\infty$（附录 5）。$H\le0$ ⟹ 边际混合对所有 $n_r$ 有益；$H>0$ ⟹ 存在 $n_r^{\mathrm{crit}} = K/H$（$K = 2\tilde\sigma_r^2(S_1+S_2)$），$n_r \ge n_r^{\mathrm{crit}}$ 时边际不混。**数值精确确认**（v11：阈值 $\|\delta\|^*=0.674$、$n_r^{crit}\cdot H = 25.866$ 恒定）。

**推论 T2（汇率）**：$\kappa_{\mathrm{ex}}$ 由 $\bar{\mathcal{R}}_T(\lambda^*;n_r,n_h) = \bar{\mathcal{R}}_T(0; n_r+\kappa_{\mathrm{ex}}n_h)$ 定义；对谱差单调增、对失配单调减、对 $n_r$ 单调减（附录 3）。

**评注**：（i）对角化估计量与完整 ridge 的差距在 Σ_r 加权风险下为 8–28%（v6），完整 ridge 的对应定理（T1-b）需 resolvent DE + 失配四阶夹心的新引理（§8 猜想已锚定对角极限）；（ii）$\mu$ 的全部物理角色：$\mu\to0$ 时 $C_\infty\to0$，恢复"无限目标数据→弃源"的经典相变；$\mu>0$ 时大数据端混合仍可能有益（$-C_\infty$ 通道）。
